Criando reações e contadores com JavaScript

Por: Instrutor Alura

Olá, estudante!

Uma das formas mais comuns de interação em redes sociais é através de botões de like e dislike. Algumas plataformas também permitem diferentes tipos de reação.

Nesta aula, você irá criar esse tipo de efeito em uma página web. Para isso, será necessário adicionar um elemento chamado button.

A tag <button> representa um botão que pode conter texto, números ou emojis. Adicione um botão simples ao seu código:

<button></button>

Adicionando emojis e contadores ao botão

Podemos inserir um emoji dentro do botão. No Windows, é possível usar o atalho Windows + V. Também é possível copiar emojis de sites e colar dentro do botão. Exemplo:

<button>❤️</button>

Ao atualizar a página, o botão aparecerá com um coração.

Agora vamos adicionar um número ao lado do emoji. Para que esse número possa ser alterado, precisamos colocá-lo dentro de uma tag. Utilizaremos a tag <span>.

<button>❤️<span>0</span></button>

O <span> será o valor que iremos atualizar com JavaScript.

Implementando interatividade com JavaScript

Até agora utilizamos:

  • HTML → estrutura
  • CSS → estilo

Agora iremos usar JavaScript para adicionar interação. No final do arquivo, depois do conteúdo do <body>, adicione:

<script></script>

Criando a função de clique do botão

Dentro do script, vamos criar uma variável para acessar o botão.

const botao = document.querySelector("button");

Ao selecionar esse botão, basicamente estamos dizendo "estou te ouvindo". Agora vamos dizer que queremos executar algo quando o botão for clicado.

O processo é semelhante ao que fizemos com os seletores no CSS. Primeiro, procuramos um seletor — neste caso, o botão — e armazenamos essa informação em uma variável.

Em seguida, olhamos para esse botão e adicionamos um addEventListener, que funciona como um evento de escuta. Isso significa que o JavaScript ficará “ouvindo” o botão para identificar quando ele for clicado.

O código ficará assim:

const botao = document.querySelector("button");
botao.addEventListener("click", botaoClicado);

Dessa forma, quando acontecer um clique, será executada uma função chamada botaoClicado.

Definindo a ação ao clicar no botão

Primeiramente, já declaramos o valor da variável que representa o botão em toda a página. Selecionamos esse botão e indicamos que o JavaScript deverá ouvir quando ele for clicado.

Como esse evento de clique executará uma ação, será necessário criar uma função. Em JavaScript, isso significa que não enviaremos apenas um comando isolado, mas um conjunto de instruções que será executado quando o clique acontecer.

Neste caso, vamos criar uma função chamada botaoClicado. Observe a estrutura:

function botaoClicado() {

}

Agora precisamos deixar claro o que acontecerá quando o botão for clicado. Uma ação simples para começar é usar console.log para exibir uma mensagem no console:

function botaoClicado() {
    console.log("fui clicado");
}

Pressione F12 e abra o console. Ao clicar no botão a mensagem deverá aparecer, indicando que a função foi executada corretamente.

Atualizando o contador de cliques

Agora que o clique está funcionando, vamos alterar o valor dentro do <span>.

Observe que, no HTML, usamos tags. No CSS, usamos propriedades com dois pontos e ponto e vírgula. Já no JavaScript, a estrutura é diferente, mas também utilizamos ponto e vírgula ao final das instruções.

Dentro do botão existe um <span> com o número 0. Precisamos acessar esse valor.

function botaoClicado() {
    let texto = botao.querySelector("span");
    texto.textContent++;
}

Observe que textContent++ soma 1 ao valor atual. Assim, o contador aumenta a cada clique.

Concluindo a implementação e próximos passos

Agora sua página possui HTML, CSS e JavaScript integrados! Você pode criar outros botões, adicionar novas reações ou testar diferentes emojis.
